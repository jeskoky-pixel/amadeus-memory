# Session 长期授权：允许学习与只读共享

统一 Session ACL 继续默认隔离。工作区成员关系不代表共享权限。

## 管理员操作

在记忆库原有四页之外的 **Amadeus 增强 → 访问白名单** 选择来源会话，勾选目标会话，再选择模式并保存。

- **允许学习（Learn）**：新建授权的默认值。目标会话可以永久保留授权期间实际取得的学习成果。撤权停止新的源记忆读取，不自动删除合法学习成果。
- **只读共享（Borrow）**：派生内容保留来源依赖；撤权后新的受控检索和注入不再返回这些内容。
- 原有授权迁移为带“旧授权”标记的 Borrow。只有管理员明确选择 Learn 并保存才升级。
- 两种授权都不赋予修改或删除源记忆的权限，也不自动允许继续分享给第三方。
- Owner 读取开关和近期动态授权不会自动授予永久学习权。近期动态只有存在独立 Learn 长期授权时才能获得永久学习许可。
- 改变无关设置、重复保存及撤销未保存修改不会重新创建授权凭证。并发编辑仍使用 revision 冲突检查。

## 可信来源链

内部账本记录实际呈现的记忆 ID、交付摘要哈希、原始内容版本哈希、稳定来源、学习者、授权凭证、交付时间和事件序号。权限枚举和管理员预览不创建学习凭证。

证据由 Host 内部能力对象提供，模型参数和 HTTP 请求不能伪造该对象。写入记忆、归属和依赖在同一事务完成。摘要开始前冻结证据：撤权后完成的 Learn 整理仍可持久化；失去权限的 Borrow 整理拒绝落库。

派生记忆保留全部保守贡献来源；再次学习时还记录直接贡献者。后台 Dream/Sleep 继续使用原算法，并把任务读取的来源并集附到内容改写或新记忆上。仅调整 importance 等元数据不会凭空污染独立事实。多次改写不能清除已有依赖。

跨 Session 检索同时检查记忆归属与原始来源限制。限制加入 SQL 后再执行 LIMIT/排序，实体事实继续按其 memory_id 继承可见性。没有原来源充分授权的第三方不能只凭中间 Session 授权读取受限成果。

## 不冻结整个会话

自动摘要和近期动态按实际事件窗口使用证据。历史中存在无法验证的旧共享内容，或已撤权 Borrow 内容时，安全回退只处理窗口中的原始用户消息，不处理可能复述旧内容的助手和工具消息。旧审计不删除，未来独立输入仍可积累。

这不是自动清洗所有历史上下文：同一模型工具写入若仍携带不可分离的旧 Borrow/未知历史，会继续被拒绝。需要完整处理助手历史时，请新建干净 Session，或由管理员审查后录入可确认的独立事实。不会自动为旧资料追认 Learn。

混合背景任务使用保守来源并集，可能使部分实际独立的内容受到额外限制；本版本不额外调用模型猜测来源，也不相信模型自报来源来放宽授权。

## 数据升级与回滚

统一 ACL 数据版本从 1 升至 2，Memory 内部 ID 仍为 `dsh-mneme`。

迁移在事务前用 SQLite `VACUUM INTO` 保存包含已提交 WAL 的一致性快照 `memory.pre-unified-learning-v2-*.db`；事务内新增授权模式、凭证、学习交付、派生依赖与迁移审计。旧授权保留 Borrow，旧 shared-history 标记保存为 `unknown-history-quarantined`，不自动公开旧记忆。重复启动不会重复迁移。

回滚必须停止 DSH，再恢复升级前安装包、配套配置和数据库快照；不能让旧程序直接读取版本 2 数据库，也不能把当前 WAL 混入旧快照。先在独立目录验证恢复结果，再替换正式路径。恢复旧快照会丢弃快照之后的数据，应另行保留新版副本。

## 可保证的范围

结构化存储、检索、注入和受控工具遵循上述限制。已经进入模型上下文或用户聊天记录的文本不会被撤权自动擦除；自然语言复述、用户复制粘贴及外部文件不可能由 Memory 绝对阻止。

注入凭证表示已构建并交付给宿主模型上下文的内容，不等同于 Provider 已实际完成推理的网络回执。字段保留原版本哈希与实际呈现摘要哈希，不允许旧凭证读取源记忆的后续新增版本。

后台请求携带可信 Host Session ID，兼容要求 Session 路由的 Provider；不修改 Provider 密钥、Preset 或权限执行器。
